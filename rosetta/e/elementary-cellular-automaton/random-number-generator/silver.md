# Elementary cellular automaton/Random number generator

**Candidate: proofs likely to discharge automatically.** Every loop is a bounded for loop and needs no invariant: the byte accumulator is modular, every neighbor index is guarded at the boundary, and the arrays are initialized by aggregates, so all checks follow from types and local guards.

Position 1262 in the [progression](../../../progression.md#stage-21), in stage 21.

## Approach

The automaton is a constant-size array (0 .. 63) of Boolean that starts with only cell 0 set; nested for loops run 10 bytes times 8 steps. Each step records the tracked cell's bit into a mod 256 byte (B := B * 2 + bit) and computes the next generation into a second aggregate-initialized array using Rule 30 as Left xor (Center or Right), with wrap-around neighbors chosen by if statements. Each finished byte is printed with 'Image and Put_Line. About 45 lines.

## Proof obligations to watch

- **index**: Neighbor indexes I - 1 and I + 1 on the wrapped 64-cell array are computed under if statements that pick the opposite end at the boundaries, so each access is guarded just before use.
- **overflow**: The byte accumulator B := B * 2 + Bit uses a mod 256 type, so no overflow check exists, and eight shifts never wrap, so the result is the faithful value.
- **initialization**: The cell arrays are declared with (others => False) aggregates before the per-element update loops, so flow analysis sees them fully initialized.
