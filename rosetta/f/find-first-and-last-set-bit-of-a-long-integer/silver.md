# Find first and last set bit of a long integer

## Approach

Use a 64-bit modular Word for the host-word case with an unrolled six-step binary search using shifts and masks in if statements, and a four-limb array of 32-bit modular values for the 128-bit case, where the same binary search runs over the limbs then within the nonzero limb. Powers of 42 up to 42^11 and of 1302 up to 1302^12 are generated by repeated multiplication with a carry-checked limb loop, and results are printed with Put and 'Image text; zero yields a specified -1 result.
