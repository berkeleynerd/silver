## Ten programs, eleven task mappings

Retain #300's original acceptance scope. Read each primary task before choosing
the final algorithm and inputs. The following are implementation requirements,
not claims of completed admission, proof or execution.

| Program/task | Required behavior and meaningful cases |
| --- | --- |
| [FizzBuzz](../rosetta/f/fizzbuzz/task.wiki) | Compute all values from 1 through 100 with the required substitutions, including multiples of both three and five. |
| [Even or odd](../rosetta/e/even-or-odd/task.wiki) | Classify actual integer values, including negative values, zero and positive values of both parities. |
| [Empty string](../rosetta/e/empty-string/task.wiki) | Demonstrate empty and nonempty String variables and their required checks; do not substitute only constant expressions. |
| [Array concatenation](../rosetta/a/array-concatenation/task.wiki) | Build and display the combined array in order from both inputs. |
| [Bubble sort](../rosetta/s/sorting-algorithms/bubble-sort/task.wiki), also [Sort an integer array](../rosetta/s/sort-an-integer-array/task.wiki) | Perform adjacent comparisons/swaps with sufficient passes and preserve duplicate values. One source serves both mappings. |
| [Greatest common divisor](../rosetta/g/greatest-common-divisor/task.wiki) | Compute GCDs with a bounded algorithm whose iteration bound covers its declared demonstration inputs. |
| [Factors of an integer](../rosetta/f/factors-of-an-integer/task.wiki) | Compute complete positive divisor lists for prime and composite inputs. |
| [Leap year](../rosetta/l/leap-year/task.wiki) | Apply Gregorian rules, including common century years and years divisible by 400. |
| [Multiplication tables](../rosetta/m/multiplication-tables/task.wiki) | Compute the full requested formatted 12-by-12 upper triangle, including headings and alignment. |
| [Count the coins](../rosetta/c/count-the-coins/task.wiki) | Compute the required one-dollar count for the specified denominations. The optional $1000 extension is excluded. |

Use faithful bounded algorithms rather than precomputed answers. Counted-loop
replacements for while loops need sufficient iteration bounds. Executable
safety guards must not silently skip required work. Derive manifest expected
