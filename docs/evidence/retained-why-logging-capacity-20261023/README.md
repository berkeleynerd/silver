# J12 logging capacity evidence

See the [source argument](../../research/retained-why-logging-capacity.md).
`check.py` performs one retained-source/identity/name-origin/arithmetic check;
it executes no target, compiler, solver, proof, predecessor checker or model.

* `inputs.json` pins retained source archives and reused providers.
* `source-witnesses.json` contains strict spans and complete-member identities.
* `writer-census.json` records logging calls, prover-field writers and the
  unselected general interrupt clients.
* `name-origin-projection.json` records all fixed prover names and log paths.
* `bounds.json` exports Q²+4Q calls, per-entry1280/256 plus one direct newline,
  whole-channel1281H, local layouts and conditional numeric guards.
* `check-result.json` and `round.json` record the focused result and work round.

The formatter is fresh per call, while channel debt/offset persist. No formatter
flush is present; output completeness is not claimed. The log-specific positive
write, clock and descriptor-lifetime interfaces remain explicit trusted service
inputs. There is no aggregate memory or stack quota.
