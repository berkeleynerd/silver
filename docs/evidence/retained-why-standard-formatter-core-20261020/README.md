# Interrupted standard formatter core packet

The [argument](../../research/retained-why-standard-formatter-core.md) extends
the fresh core's accounting to abandoned operations and later use of the two
standard globals. It requires initial default dynamic states and one cumulative
B/E budget; those inputs are not established by this packet.

`transfer.py` exports the conditional arithmetic interface. `result.json` keeps
actual joined values null. `source-witnesses.json` binds excerpts to the retained
archives; `native-bodies.json` and `native-control.json` retain selected complete
bodies, allocation/GC sites and calls from the existing disassembly, checked
against installed ELF bytes. The control inventory is evidence for review,
not automatic proof of indirect-call completeness or binary refinement.

Run only this focused comparison:

```sh
PYTHONDONTWRITEBYTECODE=1 python3 docs/evidence/retained-why-standard-formatter-core-20261020/check.py
```

The checker compares generated products and identities, tests missing-premise
and guard rejection, and checks finite event-partition arithmetic. These checks
do not prove the source induction or execute interrupted native programs.
`--write` is author-only regeneration of this packet's four products. It does
not alter earlier packets. No target, capture, disassembly, fetch, solver, Lean
or predecessor checker is invoked. `round.json` records selected versus
runtime-confirmed settings and observed time; timing is not regenerated by
the checker. Source-owned requests, A_pre, runtime R and physical sufficiency
remain distinct.
