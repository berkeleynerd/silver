# Independent scoping-review evidence

These small records publish calculations and comparisons made during
[review-ec82b4e5f2](../../../reviews/review-ec82b4e5f2.md), not new experiments
performed by the planning-correction pass. The retained original research archive remains
unchanged at evidence commit
[0cd253d05b2](https://github.com/berkeleynerd/silver/tree/0cd253d05b2cb650cc8fca81255e9a711765e16a/tmp).

- `original-manifest-audit.json`: all 2,154 original research file hashes matched.
- `T4-reconciliation.json`: curated fields versus saved run summaries, source
  sizes and copied runtime identity. Original report/session leaves were absent.
- `numeric-reconciliation.json` and `image-projection-arithmetic.json`: independent
  fits, envelope and projection arithmetic.
- `command-cap-probe.json` and `status-probe.json`: small native macOS observations;
  they do not establish Linux behavior or a completed target build.
- `prepublication-audit.md`: all 59 proposed recommendations and eight issue-draft
  comparisons. Its absolute scratch paths describe the original review host.

The original review's larger native probe sources, outputs and pinned-tool source
copies remain in its retained local evidence bundle; this directory is not a
claim that those artifacts or the original omitted sessions were uploaded.

The corrective pass also publishes `corrective-independent-review.md` and its
input hashes, plus `correction-validation.json` for the later documentation and
GitHub readback checks. The independent note records the state when reviewed;
publication deltas and recovered board access are recorded in the repair record.
