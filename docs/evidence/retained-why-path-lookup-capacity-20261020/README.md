# Restored-path direct lookup capacity, Round 33

This packet supports the [local lookup argument](../../research/retained-why-path-lookup-capacity.md)
for five selected Linux x86_64 save continuations. Immutable bucket tails,
valid heap representation and native tail-loop shape give a representation-only
chain ceiling of 2^59 and a fixed 40-byte find_rec own frame. Array capacity is
4096..2^53. These are conditional direct-work/extent results, not physical
memory, runtime-service or complete restore-table capacity.

```sh
python3 -B docs/evidence/retained-why-path-lookup-capacity-20261020/check.py
```

- `source-witnesses.json`: 16 exact retained source excerpts and identities.
- `native-bodies.json` / `native-witnesses.json`: 25 named bodies, 5,776
  instruction bytes and the identifier tag closure, checked against the pinned
  installed ELF without executing it or running a disassembler.
- `initial-topology.json`: five current-array metadata projections, joined to
  the accepted raw-block inventory and initial cut attachment. Full raw-block
  observation and predecessor checkers are not replayed.
- `transfer.py` / `result.json`: direct caller demand with explicit premises;
  absent premises leave usable bounds null. An optional actual replace-
  publication bound W sharpens L to min(2^59,7+W). Actual W remains null.
- `inputs.json`: reused dependency, projected-member and local artifact hashes.
- `round.json`: settings, task scope, measurements and validation record.

The checker checks all retained selected instruction bytes, source slices,
initial chain topology, all 42 possible table-capacity exponents with signed
index boundaries, missing-premise rejection and 576 small mutation-prefix
challenges. Finite challenges do not establish the universal semantic induction;
that reviewed argument is in the note. `--write` regenerates only this packet's
derived projections, result and manifest. Complete table/save/pipeline flags
remain false even when the inherited premises are explicitly supplied.
