# Original-construction shared-storage packet

Research for #119. The [source argument](../../research/retained-literal-original-shared-storage.md)
joins the accepted original Main/String216/helper94/synthetic173 interfaces to
incoming identifier/type/integer hashes, global/statement/alias vectors,
scalar-finalizer storage and selected finite counters. It stops after
`finalize_size_functions`, before ordinary Main analysis/gimplification.

The retained Hello result establishes the selected conditional shared-storage
interface, with at most 768 new shared GGC backing requests. It leaves complete
original gigi, Ada integer backing, later consumers, all-process/counter/
collector totals and whole-pipeline capacity open. No production behavior or
admission rule changes.

Files:

- `compose.py`: execute the pinned aggregate's source recognition and source
  checks, verify exact owned interfaces, and derive occupied/allocated/request
  bounds and guards. No native tool execution.
- `inputs.json`: 38 repository input identities, including the aggregate and
  accepted reviews. Predecessor manifests retain their historical identities.
- `sources.json`: 60 complete new-argument source/header identities, separate
  from the larger overlapping source sets verified by the aggregate Context.
- `result.json`: fresh default composition for the retained Hello source.
- `check.py` and `check-results.json`: 208 passing source-variant, mutation,
  arithmetic and independent growth-simulation checks.
- `round.md`: selected settings, actual timing, rework and residuals.

`compose.py --source PATH` substitutes actual source bytes while retaining
the selected invocation descriptor; `--descriptor PATH` selects another
descriptor checked by the inherited aggregate. These are research interfaces,
not production invocation materialization or admission. The 5000-call check
preserves the inherited conservative relocation failure; its local shared
container conditions passing does not erase that failure. Finite arithmetic
boundary checks operate directly on arithmetic helpers, without allocating
enormous source files or executing the compiler.

The packet owns new shared backings only. Existing direct identifier objects,
small-cache vectors, warning/symbol controls, String/helpers and the forced
dummy are not added again to any complete ledger. Separate filename ingress
is explicit, including one possible Image_I body virtual copy whose physical
body is already in the runtime union. B seeds only source-independent GGC
containers. Ordinary heap backings use event/insertion-derived high-water
bounds. There is no aggregate RAM bound.
