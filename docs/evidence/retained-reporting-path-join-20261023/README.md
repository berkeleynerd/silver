# Reporting with path providers and corrected warning bytes

The [source and monotonicity argument](../../research/retained-why-reporting-path-join.md)
joins exact path and private-construction providers to accepted R68 arithmetic.
[inputs.json](inputs.json) pins the bytes. [check.py](check.py) performs only
the new join, including the explicit 14-byte per-warning increase, terminal
private guards, standard-root guards and selected stdout/stderr offset guard.
No provider program or target tool is executed.

[result.json](result.json) retains the actual configuration R as unknown while
deriving a sufficient interval for it. Boundary arithmetic supports the written
monotonicity proof; it is not an empirical universal test or a selected path cap.
The [round record](round.json) distinguishes this candidate calculation from
later independent acceptance. Raw-stat paths/storage, logging, raw solver files,
startup and whole-process/full-rule capacity are not closed by this packet.
