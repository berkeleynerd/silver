# Selected SMTv2 printer six-owner interface

The [source argument](../../research/retained-why-printer-demand.md) covers
`Driver.print_task_prepared` through return or an escaping exception. Its
inputs are the accepted R61 family and the separate fixed-family syntax census.
No production or toolchain change is made.

`compose.py` calculates per-invocation and already episode-weighted process
vectors from retained dimensions. Only Ident can increment on this selected
route; the other five shared owners are zero under the source and template
origin argument. `source-witnesses.json` pins the exact source members/excerpts;
`inputs.json` pins the reused evidence without running its checkers.

`check.py` checks those identities and new arithmetic/transcription. It neither
executes a native target nor proves the universal source argument. Independent
whole-packet review and aggregate integration are separate from its finite pass.
Do not repeat a successful predecessor/native/proof run for this interface.

The output is not whole printer or whole-process capacity: attribute and private
table owners, formatter/Buffer operands, bytes and later exception rendering
remain with their respective obligations. Global e<=2/two callbacks/three saves
are unchanged; a caller must not multiply the process vectors by E again.
