installed inputs, absence of all five implicit specs candidates, complete source
identities, generated configuration headers and retained executable-root bytes.
It invokes no native tool. `result.json` records the hello-world substitution;
it is not a replacement for passing the caller's actual source.

the source partition, not as a new deployment/provenance requirement.
