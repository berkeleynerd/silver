# Candidate Z3 output capacity packet

2026-10-20 UTC; Linux x86_64; #119 / #153. See the
[source argument](../../research/retained-z3-output-capacity.md).

Run from the repository root:

```sh
python3 docs/evidence/retained-z3-output-capacity-20261020/check.py
```

The checker reads retained archives only. It checks pinned source/import
identities, reproduces the lexical member-update inventory and its explicit
non-statistics dispositions, checks source anchors, and computes the numeric
and per-family byte bounds. Synthetic formatter witnesses exercise duplicate
typed-map keys, sanitizer collisions, the empty render and a binary64 endpoint.
They do not execute the C++ code or any solver. The source argument supplies
the constructor/receiver interpretation; the checker is not a C++ type checker,
preprocessor, semantic proof or installed-binary attestation.

`sources.tar.gz` is the unmodified full archive obtained from the exact
Z3Prover/z3 revision URL in `identity.json`, 6,065,015 bytes. Full retention makes
the broad lexical census and every cited source available offline. The prior
statistics/configuration/driver and Why3-printer archive/member hashes are also
recorded; the two prior statistics sources are compared byte-for-byte.
`inventory.json` records hashes of all 2,019 scanned C++ source/header files,
all member-update candidates, their classifications and the 517-name universe.
Tests are retained but separated from the production candidate counts.

`result.json` exports the conditional **per statistics render** bound of 367,073
bytes. Complete file q, weighted O, installed correspondence and successful
discharge are not exported. No solver/target/native proof run, configuration
change, toolchain change, source pin change, admission change or GitHub write
was performed. No previous expensive evidence was replayed.

`round.json` identifies the selected model/effort, inputs, elapsed work and
verification scope. Runtime-confirmed model/effort, token and cost measurements
are unavailable. Parent integration and independent review are separate steps.
