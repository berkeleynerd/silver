`--source FILE` substitutes actual Main bytes into every component. The shared
configuration/System identities must agree. `fixture.json` supplies a complete
path bound, actual host worker/page values and the selected path class; it is
not a production launcher. `--frontend-packet DIR` locates the lead's frontend
packet before integration. It defaults to the adjacent packet afterward.

`inputs.json` pins the reused formulas/results/source arguments; their existing
manifest checks remain in force. `compose.py` also reruns the existing offline
linker and binder-option checks once per Context. `check.py` reuses that Context
across source/interface variations, including trivia above the current byte cap,
column and worker overflow, wrong path width, syntax and configuration mismatch.
No successful native execution is repeated. `result.json` is the selected fixture
substitution; `check-results.json` records the thirteen interface checks, including
the socket directory's equality with the selected writable TMPDIR and exact
options-content/hash/argument bindings when the worker count changes.

The result distinguishes arithmetic failures, open interfaces and conditional
closure. It retains external source/ABI/service assumptions and parent
materialization of the computed launch graph. It does not change admission or
supply production SPARK/Lean correspondence. The next research dependency after
