# Fixed-forest shape transfer evidence

Research #119 / #153, 2026-10-20, Linux x86_64. See the
[source argument](../../research/retained-why-session-shape-transfer.md).
This packet derives per-save J insertion calls and full, untruncated L
Shape-buffer bytes for five exact retained forests. It imports successful
opening certificates and typed atoms; it does not rerun their extraction or
establish complete-save/counter/pipeline capacity.

- `inputs.json` pins exact source archives/files, atom gzip files and saved
  occurrence certificates. Atom author freeze is
  `0ec7f4b5082830501f51764bfd4652d157c31104`.
- `source-witnesses.json` retains 23 coordinate-checked excerpts, including
  the actual decoded-name/quote-suffix and attribute-union branches.
- `transfer.py` implements the conservative mathematical interface. Unknown
  atom forms leave L null. Explanations are direct dictionary insertions, with
  a separate nullable E(p); they are not Shape-buffer output.
- `bounds.json` retains all task/visit-derived bounds and guards;
  `check-result.json` records the focused comparison and its measured time.
- `test_transfer.py` has six small interface regressions, not a native test
  or a universal proof. `round.json` distinguishes selected settings, missing
  runtime/token/cost evidence and actual work.

From the repository root, after integrating the pinned atom packet:

```sh
python3 -B -m unittest discover -s docs/evidence/retained-why-session-shape-transfer-20261020 -p test_transfer.py -v
python3 -B docs/evidence/retained-why-session-shape-transfer-20261020/check.py
```

`--atoms-root /path/to/atom-packet` selects the same hash-pinned files in an
isolated worktree; this option was used before integration. `--write` refreshes
only derived `bounds.json` and `check-result.json` after an intentional change.
The checker hashes retained inputs and checks source slices/JSON arithmetic;
it starts no target, debugger, compiler, solver, binder/alpha replay or public
evaluator. A passing check does not independently establish the source proof,
typed-memory interpretation, live configuration or saved-artifact invariants.
