Run the focused reconciliation from the repository root:

The check compares four generated JSON values, reprojects 27 source excerpts,
checks 85 retained native bodies (15,600 instruction bytes) against the installed
ELF, verifies selected allocation-site/layout constants and evaluates five
compositions. Premise omission/falsehood and a failed sentinel guard suppress
actual exports. Buffer capacity boundaries and invalid extents are checked.
It does not execute the target or any predecessor checker.

Files:

* `transfer.py`: disjoint cumulative request arithmetic and fail-closed interface.
* `result.json`: candidates/default null exports and explicitly conditional joins.
* `inputs.json`: byte/hash identities of accepted results, notes and source archives.
* `source-witnesses.json`: bounded retained source excerpts.
* `native-bodies.json`, `native-witnesses.json`: existing disassembly projections
  and exact ELF identity. The byte checks are correspondence evidence under the
  named external behavior relation, not a proved binary refinement.
* `native-allocation-sites.json`: all constant minor-reservation sites and heap
  header literals in these bodies, including visible but unreachable generic
  branches and expressly excluded structural callbacks. Site sums alone are
  not dynamic bounds; the note supplies occurrence and reachability arguments.
* `round.json`: authorization, settings, timing, review target and limitations.

The retained source/native inputs are the same OCaml and Why3 revisions as the
accepted packets. `--freeze-native --write` projects existing evidence and writes
this packet's derived data; it does not fetch sources or run a disassembler.
Ordinary checking requires the installed executable at the path in
`native-witnesses.json`. Source/archive/executable hashes must match.
