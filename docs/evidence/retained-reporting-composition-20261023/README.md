# Conditional selected reporting composition

The [source argument](../../research/retained-why-reporting-composition.md)
composes the current J12 canonical JSON, other-warning and terminal byte
interfaces with R66's one shared-stderr fragment and two exit flushes.
[inputs.json](inputs.json) pins the exact provider bytes; [compose.py](compose.py)
performs only the new join. No provider program or target tool is run.

[result.json](result.json) preserves the remaining path operands symbolically
and separately evaluates the terminal packet's orientation point. Passing
there does not attach actual paths or prove production/process capacity.
Independent acceptance belongs to the later R68 checkpoint, without rewriting
these author-result flags. The [round record](round.json) reports available measurements;
root live settings and isolated token/cost telemetry are unavailable.
