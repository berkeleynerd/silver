# Native and semantic branch-join associativity

`Silver.ApplicationPackageFlowJoins` passed a focused Linux x86-64 check and
fresh audit of 5,392 declarations using two workers, two threads and 8192 MiB.
Every captured input hash matched before retention; [index.json](index.json)
records the exact run and compressed evidence. This is partial validation.

The interval, range-map, path, semantic-flow and native active-flow joins are
associative over their full domains. Semantic flows are also commutative. Empty
interval normalization, absent scalar slots, unequal native value-list lengths
and unreachable invalid-input paths are included. These results bridge the
native conditional's left accumulation with nested semantic alternatives.
The first draft exposed premature expansion of interval joins during empty-case
normalization; explicit normalization lemmas repaired it. A subsequent reservation
attempt ran no Lean because all eight host workers were occupied. No native
source, input domain or trust assumption changed. No full feature assurance or
independent kernel replay is claimed. Selected GPT-6 Astra Max; runtime settings
and token/cost measurements were not independently exposed.
