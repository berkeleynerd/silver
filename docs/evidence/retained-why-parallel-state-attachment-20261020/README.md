# R55 post-registration state attachment

See the [source argument](../../research/retained-why-parallel-state-attachment.md).
The default unmasked mutable-state obligation is **open**. The packet identifies
installed publish-before-counter and partial-ephemeron-copy windows, preserves
the CE fold's second root, derives a first-resize trigger from all five actual
R53 contexts, and supplies a conditional mask/resource/state guard.

```sh
python3 -B docs/evidence/retained-why-parallel-state-attachment-20261020/check.py
```

The check binds source/evidence identities, reproduces only the new raw-context
projection, and compares 3,082 instruction bytes in six bodies with the pinned
installed ELF. `--binary PATH` permits the same byte-identical ELF at another
location. It does not run the ELF, a predecessor checker or a captured-memory
reader. `--refresh` is the explicit projection-generation mode.

- `raw-contexts.json` retains every non-goal declaration/tag and each resize key.
- `source-witnesses.json` pins 24 files and 44 excerpts from retained archives.
- `native-witnesses.json` contains six body instruction projections.
- `native-mutations.txt`, `native-symbols.txt`, `native-query.json` retain two
  target-free static GDB queries. The hashcons body is reused from the older
  retained static disassembly. No successful native capture was repeated.
- `inputs.json` separates repository and local evidence inputs.
- `companion-freeze.tar.gz` retains all fourteen exact owned files from reviewed
  companion `bb9bc85d36e5a8ea47c1fefe09ad4f71ae86d822`. Its file identities and
  commit are pinned in `inputs.json`; the companion checker is not rerun.
- `result.json` and `round.json` distinguish scoped source conclusions,
  conditional failure schemas, validation, rework and remaining integration.

The initial-family transfer uses the pinned, conditionally accepted companion
R55 logging-prefix constructor-trace relation, with its source/resource/control
guards. Input's old post-CE table is only an overapproximation
of its old registration prefix; it is never equated with the new registration
table. The proposed inherited SIGINT mask is source-analyzed, not adopted or
observed. The global two-callback / three-save / e <= 2 budget is unchanged.
