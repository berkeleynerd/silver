## The original signature equality

A procedure formal carries a positive nominal `Type_Id` for an array input. In Lean, `formalType` looks up the corresponding entry and uses both its index and component bounds. For example, the admitted `Copy_Size` fixture declares `type T is array (1 .. 2) of Integer` and takes `Data : in T`. Looking up the positive ID in the old default table `[]` yields `emptyType`, whose two intervals are both `1 .. 0`. The old equality fails for this signature even though it still gives the right number of procedures. Scalar formals use their own kind and bounds when the ID is zero.
