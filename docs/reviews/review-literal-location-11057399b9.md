## Complete selected location demand

`linemap_init` value-initializes ad-hoc population/capacity/data before creating
its ordinary hash; the retained compiler then installs the GGC reallocator.
The initial 127-slot/1,016-byte ordinary hash and control are prefix-owned.
An initialized empty hash is not an absent hash, and the GGC data array is
initially absent. GNAT's scanner, ordinary-map preallocation and `Sloc_to_locus`
do not call combined-location constructors. The imported original-tree and
scalar-helper paths preserve scalar loci; `set_block_for_group` assigns the
group's lexical field, and `gimple_bind_set_block` is not `gimple_set_block`.
No prefix population is silently borrowed from null Main.

`get_or_create_combined_loc` has at most one INSERT lookup and one append per
request. Its early returns, compact representation and key hits can reduce
work but are not subtracted. PCH reconstruction is the other writer and is
excluded by the selected route. There is no selected reset/deletion/recreation
of the global ad-hoc table.

The three positive request owners are disjoint:

- Each initial direct-call builder invokes `gimple_set_block` once: **C**.
  The subsequent scalar location setter does not create another combined
  location, even though it may copy a warning disposition.
- CF assigns blocks to the accepted corrected initial tuple/bind population:
  **4C+2N+2**. Processing the outer bind directly leaves the conservative slot
  used for a possible synthesized fallthrough return. The explicit bare return
  excludes that actual branch. Descriptor call actuals are VAR_DECLs, so the
  separate EXPR_P argument remapper is absent.
- Initial CFG discriminator assignment visits at most **3C+N+2** surviving
  statements and **N+3** edges, with no PHIs: **3C+2N+5**. The CFG is a straight
  path; calls can unwind externally but create no local EH edges or extra
  ordinary successors. Charging every statement/edge is conservative even
  when equal locations reuse a previous replacement.

Thus **Q=8C+4N+7** bounds attempts, hash lookups and fresh entries. The helper
frontier is justified by actual scalar/reserved-location bodies and lack of
ordinary lowering, not solely absence of emitted code. The retained selected
body/options exclude debug/clobber and value-expression block clearing,
local EH reconstruction, inlining/cloning/region moves, replacement folding,
target multiversioning/varargs, real-SSA/PHI/loop copying and instrumentation.
RTL, frame/CFI and unit emission copy encoded locations without reentering the
combined constructors. The source argument keeps successful compilation and
its warning-policy/representation premises distinct from unpriced error paths.

The unsigned CFG ID advances at most once per call and twice per ordinary
single-successor block, hence **C+2(N+2)**. Per-line discriminator increments
are bounded by that monotone endpoint. Both the unsigned storage guard and the
explicit signed-32 conversion guard remain, covering the `int` constructor
