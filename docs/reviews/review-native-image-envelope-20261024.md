## Actual frontend and native attachment

The classification is attached to frontend entity provenance, not a successful
fixture or a known runtime Image length. Is counts selected distinct signed
index-subtype identities with low literal 1 and high the Natural position
capture. Ia counts the corresponding distinct constrained String subtype
identities. Copies qualify only when they preserve the specified endpoints,
capture type and local context, and their distinct identities are counted.
Thus the result is not a constant multiplier per source Image occurrence and
does not classify every internal constant or every String subtype as Image.

The actual Ada 2022 dispatch supports the claimed producer. The retained
`Image_Should_Call_Put_Image` body tests explicit/inherited aspects, nonscalar
types and the relevant itype aspect case; predefined Standard Integer satisfies
none. `Expand_Image_Attribute` therefore selects Image_Integer and emits Snn,
Pnn and the suppressed `Snn(1..Pnn)` slice. The source argument E is analyzed
separately and does not become this slice's high-bound initializer.

Range forcing captures the scalar Pnn with its **existing Natural type**.
The generated constant has no Current_Value substitution, and a later force
of its constant identifier does not recapture it. The copied slice range
preserves these references. Natural's Esize is 32 despite RM_Size 31; gigi's
same-Esize signed-base rule selects a signed 32-bit native representation.
Runtime nonnegativity cannot replace that representation with unsigned32.

The capture's native declaration is readonly and nonvolatile, with the mutable
Pnn declaration as initializer. It is not TREE_CONSTANT, so identifier lowering
does not replace it with the initializer. There is no address clause,
by-reference parameter, renaming or aggregate branch on this selected scalar.
Local elaboration either keeps that declaration or creates at most one extra
readonly debug VAR_DECL of the same Natural type, initialized by the existing
declaration. The static low endpoint disables debug-variable creation.

The extra debug variable is counted: one VAR_DECL and one DECL_EXPR per Is.
Its initializer is type-compatible and local, so `add_decl_expr` retains it
and does not generate INIT_EXPR. Its declaration layout copies completed
constant Natural sizes. Names, binding/statement lists and other metadata
remain separately owned; they are not included in the raw declaration bytes.

## Shape and reachable folds

The superflat predicate is justified by source types: the high endpoint's
Natural lower bound is 0, and the selected low endpoint is 1, so
`0 >= 1-1`. The dynamic GE/COND and lower-bound-shift alternatives are absent.
The repaired 27Ia predicate allocation allowance remains in the general
kernel. Maximum-size queries on the capture's declaration initializer stop
at constant type extrema; they do not recursively expose arbitrary arithmetic
from E or follow an initializer chain indefinitely.

Natural32-to-Integer32 followed by unsigned64 conversion contracts the
same-signed intermediate conversion. Range creation converts to the incoming
base sizetype, so it does not introduce a distinct range-subtype conversion.
The length computation is unsigned64 `1+(X-1)`, with
`X=NOP_u64(V)`. Negation of the constant, canonical operand ordering,
constant association and the zero identity return X. The identity is valid
modulo 2^64, including the boundary; it does not require the runtime range.

Bit-size conversion may retain the second widening, producing
`MULT(NOP_u128(NOP_u64(V)),8)`. In particular a negative signed32 value yields
a different result if the intermediate unsigned64 conversion is removed;
the native simplifier does not get to assume Ada runtime nonnegativity here.
Byte multiplication by 1 is identity. The multiply-by-8 graph is already a
multiple of its alignment: `multiple_of_p` tests the constant factor first.
Round-up therefore adds only its already charged divisor constant. SAVE
processing reaches the readonly, side-effect-free declaration and returns the
existing graph. This establishes the absence of a newly created SAVE node
from source conditions, rather than from the presence of a SAVE helper call.

The matched binary rules on this domain are the zero/one identities,
MINUS-to-PLUS and constant association. The matched conversion rules preserve
or shorten the permitted conversion spine. The other retained root forms
require absent nested operators, literal kinds, equal dynamic/literal captures,
two conversion operands, SSA names or incompatible constants/types. The broad
zero-one predicate cannot admit factor 8; factor 1 has already returned at
the identity. Its GENERIC known-bit query does not invoke SSA range analysis
on this declaration/conversion grammar.

The handwritten folder does not add another successful symbolic rewrite.
The terminal PLUS/MULT association scan finds only two objects and fails the
strictly-more-than-two guard, though its possible overflow-clearing candidate
is charged. For multiplication, `extract_muldiv` stops at the unsigned

construct the converted factor 8 and then fail at V. That discarded candidate
is charged. The unary tail's narrowing-multiply and other expression-shaped
branches are excluded by the selected widening/declaration operands.

The finite phase rank accounts for recursive calls, not just final nodes.
Canonicalization removes the pending constant-left order, association removes
the inner arithmetic operation, MINUS advances to terminal PLUS, and conversion
contraction shortens the spine. No selected rule recreates an earlier phase.
The permitted multiplier extraction follows a shorter spine to V. GENERIC
replacement captures are used once, so repeated-capture unsharing is absent.
Exact-type association views allocate nothing, and non-lvalue identities
return the existing conversion rather than wrapping a declaration. These
facts justify the finite specialized envelope without pretending that operand
height alone ranks the MINUS-to-PLUS edge.
