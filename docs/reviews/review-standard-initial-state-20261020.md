## Critical challenges and disposition

- **Actual cuts and the controlled signal premise.** The join attaches
  Put_Line/17310, Put/17514, First_Or_Default/17631, Is_Message/17704 and
  Input_Is_Valid/17869 to the same process records, argv/environment, load
  biases and persistent gates as the accepted providers. The selected ELF is
  `7c8c302f65a98e66159f6514045f4c2634aab5c556eea0a7d6fd1f39dc35a368`.
  The first four cuts are scheduling `Gnat_checks.iter` entries; the fifth is
  the first cvc5 `inline_trivial` entry inside the first preparation. The
  accepted query is target-free and reports default SIGINT Stop=Yes/Pass=No;
  it is not a newly observed inferior policy. Matching debugger bytes and
  environment, fixed `-nx -q -batch` launchers, the sole continuation and
  successful endpoint control attach that accepted exclusion to these same
  prefixes. Input additionally has zero unconditional save-root guard hits.
  The four startup GC events remain recorded. SIGVTALRM's direct pending-bit
  path remains permitted and has its returning owner; no all-pending-actions
  or suffix no-signal assumption is introduced.

- **Abort cannot recover registration after ordinary output failure.**
  `iter_leafs` protects the callback-bearing `List.iter` and consumes exactly
  `Not_found`. Abort's fixed record has three constant keys and only String,
  Bool and empty-List values. Its sort, escaping (including all-byte hex),
  typed `%a` callbacks, private fixed-box parsing, Format operations, Buffer
  leaves and channel callbacks do not call JSON getters or arbitrary printers.
  The relevant explicit failure constructors are distinct from `Not_found`;
  Queue/Stack `Empty` is not that constructor either. Native channel errors
  select `Sys_error` or `Sys_blocked_io`, and mutex errors select those
  documented service/allocation families. The argument correctly includes
  pending-action replacement inside `caml_raise`, rather than assuming the
  original exception is always preserved. The accepted signal/client relation
  closes that replacement route for these prefixes.

- **Nested and outer error handlers do not restore a cut continuation.**
  A `Failure` from location parsing or its abort can be caught by the surrounding
  label parser. That handler builds a private fixed `%s` message and aborts
  again; it performs no lookup that converts the post-write path into
  `Not_found`. The earlier location handler uses concatenation. A failure in
  the outer GNAT or uncaught reporting handler cannot reinstall the unwound
  registration or module-initialization continuation. Successful abort reaches
  exit, which would consume a persistent hook gate; nontermination cannot
  reach the observed cut. This permits failures and partial enqueues instead
  of assuming valid labels, successful writes or transactional Format state.
  The absent limit-line/region option paths have different catches and are
  excluded by argv. First-split initialization calls the fixed first transform;
  the further-split `find_next_transformation` abort is outside these prefixes.

- **The stderr driver diagnostic has a different receiving path.**
  `Printer.int_of_string` catches conversion failure, prints to stderr, then
  raises `Assert_failure` if printing returns. Its `iter_group` caller does not
  recover the diagnostic. `Loc.try2` wraps or reraises; driver loading,
  `load_drivers` and `create_controller` do not return a usable controller
  after that failure. The create-controller call is outside `init_cont`'s
  session/add-file/reload handlers. Partial diagnostic failure therefore also
  unwinds before registration. Later syntax substitution and model/result
  diagnostics require the printing/prover paths excluded by the actual guards;
  CE-off is not substituted for a task-meta theorem.

- **The complete prefix partition accounts for mutators, not only bytes.**
  Reused profile/Debug results classify aliases, setters, initialization,
  selected plugins/compiler-loader effects, CLI routes and all enabled-output
  clients. Exact config fields exclude the pre-hook warning arms; later
  warnings have the private warning-list hook. Disabled Debug formatting also
  covers the interval when Debug still points to stderr, with caller argument
  evaluation retained in the reasoning. Ordinary ending has not been entered;
  synchronous scheduling and the classified native clients prevent an earlier
  ending or a suspended writer from entering the cut by another callback.
  Persistent gates exclude even a failed earlier Format exit flush. Private
  formatters and direct channel writes retain their own state. Thus the
  partition covers empty flushes, resets, geometry changes and partial dynamic
  operations as well as successful output. It relies on the accepted typed,
  fixed-loader/no-reflection relation, not lexical-search completeness alone.

- **Both first-transform branches are included.** `Driver.update_task` uses
  closed task/declaration/meta callbacks. The false-meta branch removes unused
  declarations/terms; the true-meta branch traverses predecessors, opens and
  substitutes terms, and uses the local symbol/declaration memo owners. Neither
  branch obtains a standard formatter. The true branch's Debug sink and the
  driver before/update/after sinks are disabled by the accepted flag induction.
  Pretty printers passed to ignored formats are not invoked, timing updates
  use private tables, and any warning uses the installed private hook. The
  observer has exactly one preparation and `inline_trivial` has not begun;
  no prior preparation failure is hidden by assuming an empty current queue.

- **Constructor identity and preservation are source-derived.** A first
  standard dynamic mutator would belong to one of the classified rows and
  contradict its selected-input, ownership, gate or no-recovery exclusion.
  The reachable stderr setup only changes callback fields. Therefore the
  source constructors, rather than Debug's observed graph, supply the states.
  Each queue has one cell, first=last with Nil tail, containing the unknown-size
  `Pp_begin(0,Pp_hovbox)` of declared length zero. Each scan stack has two
  entries: the top at left_total 1 shares that same token; the distinct sentinel
  at -1 contains unknown-size empty text of length zero and is not in the
  queue. Format/tab/tag/mark stacks are empty. Totals/depth are 1, space is 78,
  indent 0, newline true, margin/minimum/maximum indent 78/10/68, maximum boxes
  `2^62-1`, ellipsis `.`, and tag switches false. Stdout and stderr have distinct
  constructor allocations and mutable graphs. Stdout has the default channel
  callbacks; stderr has exactly one captured newline-then-channel-flush wrapper.
  These logical object counts are an initial storage seed, not a complete
  physical-storage upper bound or an assertion that channel buffers are empty.
