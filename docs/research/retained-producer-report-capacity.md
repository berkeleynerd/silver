## The order of conversion is part of the argument

`common/call.adb:132–142` translates an unsuccessful `Read_File` result into
`Invalid_JSON_Stream` with `Format_Parsing_Error`; it returns the value only
on success. The driver waits, deliberately ignores the child `Success`
Boolean, and parses the same merged tempfile before deletion
(`gnat2why-driver.adb:243–268`). There is no exit-status/schema gate here.

`Parse_Why3_Results` (`gnat2why-error_messages.adb:543–1336`) executes these
operations in order:

1. Mark subprograms with no VC proved. This can change claims before the read.
2. Read `File`, then extract and copy `File.results` as a JSON_Array. This
   precedes even the test for an `error` member.
3. If an error exists, convert its string and optional Boolean `internal`,
   then invoke the nonreturning error handler. A well-formed isolated error
   with `results:[]` follows this route; `{error:...}` alone need not.
4. Convert `entity`, process timing entries, and call `Parse_Gnattest_Values`.
   The selected empty GNATtest-values option excludes its external input path.
5. For each result, parse extra info, the id/kind/result and optional metadata;
   rename its VC_Table entry; eagerly decode the complete counterexample
   list; copy Check_Info; allocate `new Fuel_Type'(250_000)`; and copy its last
   counterexample record. These declarations run before the RAC enable/result
   test (`:843–881`).
6. With CE checking disabled the RAC/fuzzer branch is skipped. It does not
   undo the preceding CE parser. The later pretty-CE initializer in
   `Error_Msg_Proof` also parses its supplied last counterexample.
7. Emit the proof result, free Fuel on normal return, then process the next
   result. Finally print each response warning using Text_IO.Put_Line.

The isolated terminal error, intact canonical response, invalid JSON, schema
conversion error, semantic identifier error and I/O exception are distinct
alternatives. Only Invalid_JSON_Stream is caught by this procedure. Wrong
discriminants, missing required fields, enum `'Value`, Integer/Float/Natural

leak that one allocation; later results in this invocation are not executed.
