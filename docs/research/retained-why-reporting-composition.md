2026-10-23 UTC, #119 / #153. **Candidate, pending independent review.**
This joins the current J12 canonical-response JSON inputs, other warnings and
post-registration scalar terminal diagnostics. It supplies a computable

## Inputs and owner boundary

Use the exact five process rows of the
[canonical JSON input](retained-why-canonical-json-input.md), including current
J12 registration and scheduling bounds. Let `Q` denote that row's scheduling
bound E, to distinguish it from the formatter event count below. Each row

```
B_JSON = b + 3*W_o + 6*L_o + 6*X
E_JSON = e + 3*W_o + 2*L_o + 2*X.
```

`W_o/L_o` are the complete initial and suffix other-warning count/byte exports
of the [warning argument](retained-why-diagnostic-warnings.md). Canonical parser
warnings are already inside `b/e`; do not add them again. The final debug-buffer
copy is likewise already included. The
[terminal argument](retained-why-terminal-diagnostic-bytes.md) supplies
`X=2*x_abort`, the sum of both possible abort-message payloads, as a computable
function of actual selected path maximum P and intact canonical response-line
maximum M. X is not the length of just one exception report.

Retain each provider's source/native/service relation and fresh nonreplay,
CE-off, no-manual J12 domain. In particular, the exclusion of model-parser
stderr uses the actual selected `get_model=None` attachment; the user-facing
CE-off option alone is insufficient. The canonical-file result remains
conditional on the future proxy's faithful bounded publication and response
refinement. Cancellation and failed publication do not supply a raw-file
fallback. The one global e<=2, two save-entering callbacks and three saves are
not renewed at a reporting boundary.

## Complete selected standard-core writer sum

The accepted [writer/control partition](retained-why-standard-formatter-control.md)
leaves four selected standard-root writers: ordinary JSON, abort JSON,
Printer's integer diagnostic, and the gated exit flushes. Ordinary and abort
JSON, including abandoned prefixes, are already in the JSON schema.
[R66](../evidence/retained-printer-output-round66-20261023/README.md) exports
`64*Q` text bytes and `8*Q` events for the integer diagnostic, **once per
process**, even though its three driver rows repeat the same fragment. The
persistent exit gate contributes at most two flush events for both roots
together. Therefore use

```
B = B_JSON + 64*Q
E = E_JSON + 8*Q + 2.
```

This is a conservative sum across distinct stdout/stderr cores. Do not reset
their state after a catch or charge the fragment anew per driver. The accepted
[constructor-state argument](retained-why-standard-initial-state.md) applies
through the following source transport to the
[combined prefix](retained-combined-parallel-startup.md); no mutable state is
copied between processes. All five current cuts precede scheduling, including
Input's registration cut, which is earlier than its historical first-CE cut.
R55's [J12/logging control](retained-parallel-logging-prefix.md) places the
changed parallel callback use after registration. Logging.init opens and
assigns its own channel without invoking either standard formatter. The quiet
and timeless edits change private driver/configuration data; an initial syntax
diagnostic cannot return to the cut through controller construction. The exact
argv/environment still excludes debug and GNATWHY3LOG, and the retained
controlled-prefix relation excludes pre-cut SIGINT/save delivery and unwinding
registration. The classified returning Thread/SIGVTALRM/native clients remain
permitted and retain R42's standard-root preservation argument; this is not an
assumption that no pending action or handler ever runs.
Persistent exit gates exclude an earlier completed exit. Thus every row of
R42's complete standard-mutator partition retains its exclusion; the one
Debug callback installation still changes no dynamic core state. Both roots
reach these controlled cuts in constructor dynamic state. This transport
requires the named controlled-prefix/native-service conditions; it does not
establish failed-startup capacity or enforce a signal mask for production.
The warning hook and Debug statistics have private owners. Their returned
strings become JSON input where explicitly charged, not additional standard
Format calls. Direct fallback and raw-backtrace writes belong to the channel
sum below, not this E.

Instantiate the [interrupted-core theorem](retained-why-standard-formatter-core.md):

```
L = B+E
I = 3*E+2
T = 1000000010+L+1

L+79 <= 1000000010
```

These are checked arithmetic conditions on derived operands, not an invented

## Channel output and retained conditions

at most `Y_format=B+70*(E+2)` bytes together. The terminal interface supplies
`2*Y_terminal+253` direct stderr bytes. The warning interface separately owns
at most two 59-byte missing-parent raw-backtrace prints. Thus a conservative
combined channel offer is

```
Y_channels = Y_format + 2*Y_terminal + 371.
```

Y_channels covers only the selected stdout/stderr reporting offer; the logging
channel and raw/backend files retain their own owners and bounds.
This matches the earlier
[channel interface](retained-why-standard-channel-capacity.md), with both
fallback string lengths bounded by Y_terminal. An embedded backtrace already
inside X is not added again; these four direct prints have different call
sites. The channel transfer's valid entry state, inherited-descriptor service
and prospective pipe-launcher conditions remain required. Using Y_channels
for each separate offset guard is conservative, but does not double the
aggregate output claim. C stdio/raw-descriptor writes have separate owners.

checkable conditional calculation. It is neither a measured pathname maximum
