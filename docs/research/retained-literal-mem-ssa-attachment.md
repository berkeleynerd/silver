## Actual-source interface adaptation

The evaluator calls the accepted 149-guard wrapper using the actual descriptor,
Main source override, path/runtime class and configuration. It recognizes the
raw Main bytes again and checks identity and the **complete** recognized
counts before attachment. MEM receives the actual core and actual evaluated
shared-query lifetime:

```python
mem = mem_leaf.evaluate_source(raw, selected['core_result'],
    selected['selected_native_shared_query_lifetime'], mem_context)
```

That accepted callable checks operation, initial SSA/helper, backing,
chronological RTL shape, emission and shared UID owners for these bytes.
The wrapper checks the returned leaf's identity/counts and disjoint owners.
An equal C/N pair does not permit substituting another source's evidence.

`evaluate_source`. The new `ssa_extension` therefore adapts the accepted
**source argument**, rather than calling or generalizing that sample checker.
For actual recognized C and N, it calls the existing pinned
`native_initial_ssa_lifetime(C,N,core_context)` and requires equality with the
**entire** actual core initial SSA owner, including request groups, ordinary
requests and arithmetic checks. It additionally reconciles its definition,
vector, slab, default-key and scalar-registration ownership. The reviewed
selected-pass mutation-state argument then supplies zero later names,
name/free-list/default-map backing and operand slabs beyond that initial owner.

With `u=3C+1` and `L=1+[u>25]+ceil(max(0,u-127)/409)`, the unchanged owner is
