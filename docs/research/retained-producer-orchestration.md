`Call_Gprbuild` supplies one selected target and `-c`; data representation omits
`--gnatprove`, while the other two calls select their separate frames/translation
databases (`gnatprove.adb:177–330`). The generated configuration comments retain
those actual gprconfig commands. Their inputs and source extents are:

| GPR child | Configuration bytes | Naming pragma bytes | Aligned GPR configuration extent |
| --- | ---: | ---: | ---: |
| Data representation | 6,741 | 327 | 8,192 |
| Global/ALI generation | 6,951 | 327 | 8,192 |
| Translation | 7,015 | 327 | 8,192 |

Each configuration and project has no import or extension. Each GPR process
loads its project, its configuration and Main through Sinput. Its generated
327-byte naming file belongs to the child compiler, not the GPR source table.
The complete load frontier, pathname deduplication and Main subunit-reader
behavior are the same [GPR source-read argument](retained-gpr-parent.md#complete-native-sinput-load-frontier).
Main contributes a complete physical buffer and a leading-trivia scan; its first
token is always `procedure`, and no Main Ada tree is built in this parent.
GNATprove's own GPR2 discovery makes zero Main text/ALI parser calls on the
[indexed route](retained-producer-parent.md#gpr2s-indexed-main-read-projection).

The fresh phase directories contain no prior `.cswi` file or generated object.
GPR checks the missing object/dependency, then the missing switches file before
`Process_ALI_Deps` (`gpr-util.adb:5701–5748,5810–5879`). `Call_Gprbuild` selects
`-s`, so the switch check applies. Translation receives a copied phase-1 ALI,
but no copied switches file: `Copy_ALI_Files` copies only `*.ali`
(`gnatprove.adb:444–537`). Thus no up-to-date checksum or recursive ALI dependency
walk reads Main before compilation. This argument does not cover arbitrary
incremental or prepopulated directories.

Write `q(B)=4096*ceil((B+1)/4096)`. In **each** child, the fixed project and
configuration contribution is `4096+8192=12288`. The sufficient source-position
condition is therefore

```text
12288 + q(Main_bytes) - 1 <= 2147483647 - 4096.
```

As in the native parent, separately require each buffer's EOF index to fit,
`32*line_capacity <= 2147483647` for the doubling line table, and expanded
physical columns at most 32766. FF/VT do not reset physical columns. Do not
sum the three independent GPR source tables. The retained configuration
spelling and path-length/equality class are part of this component's context;
relocation or changed template widths require recomputing their extents.
The PID suffix occurs in a header comment; replacing its recorded six digits
by the full ten-digit signed32 envelope leaves each configuration below 8192.

## Generated ALI and parent continuation

After each child returns, `Phase_2_ALI` asks `Scan_ALI` only for DW; U is
unconditionally enabled, and A/G/QQ/X data is skipped
(`gprbuild-compile.adb:2011–2065`, `gpr-ali.adb:673–677`). The null producer's
U/W/D projection has one Main unit, at most one implicit System with, and two
dependencies. Data representation has no W. These are fixed names and
cardinalities for the token family; increasing trivia changes only fixed-width
timestamps/checksums or already bounded source coordinates in ignored records.
The parent parser therefore adds at most one ALI, one unit, one with and two
dependency entries, and no stored A rows. Existing table initial capacities
suffice; the [native parent](retained-gpr-parent.md) supplies their storage
argument. There is no library/interface, subunit or native post-link path.

The implicit `Z system` row is selected as a W record
(`gpr-ali.adb:1164–1181`). `Queue.Insert_Withed_Sources_For` only looks it up
among the existing project sources (`gpr_build_util.adb:2328–2405`); it does
not load System into this process's Sinput. The System mapping is an input
to the compiler child, whose source tables are charged separately.

The raw ALI buffer still contains every row, even skipped rows. Use the
[producer envelope](retained-producer-parent.md) **29,622,804 bytes**, plus EOF,
for both gnat2why phases. For data representation use the deliberately larger
[compiler component](retained-producer-datarep-null.md) envelope **2,177,456
bytes at P=512**, plus EOF. Their actual retained ALIs are 1,305 and 387 bytes;
those observations are not the universal bounds. The unchecked native
378-byte ALI specialization is not substituted for the producer variant.
Under `GnatProve_Mode`, the parser also scans the skipped suffix for the fixed
`GG EK_END_MARKER` marker (`gpr-ali.adb:1433–1465`). The complete raw ALI bound
covers its `P`, `First_P` and `Last_P` positions, including those skipped lines.
