prover equality, driver loading, theory preparation and identifier
registration. RC values do not retain parser locations. Its enlarged command
does not register a filename in `Loc.FileTags`. Its lexer uses the independent
`Rc.buf`; it does not alter driver `Lexlib` string/comment scanning.
Consequently the timeless driver's non-time token stream, one possible extra
filename, location ordering and semantic/cache request relation are unchanged
by the quiet command edit.

Conversely, the time-directive removals do not change any RC string, key,
quoted-field length or buffer growth. The command-only proof's maximum
272-byte buffer backing, lexical action counts and 4,096-word allowance remain
valid. Driver objects do not store the command. Input_Is_Valid's one
`get_complete_command` copy still occurs before its first inline entry;

reaches `actualcommand`, command argument queues or server serialization.
Removing the private time regexps cannot disturb command parsing before
those cuts, and the later selected ordinary quiet command still has only
`%f`, with no resource-limit substitution.

The two changes therefore have disjoint varying allocation subtraces, apart
from their common allocation counters and remembered table. Those counters
are handled by addition. They need not execute in disjoint time intervals.
Unchanged objects retain their minor/major classification until the first
collection. Shared lexer runtime position records are separately charged by
each source trace. Both recipes preserve the identifier/driver registration
