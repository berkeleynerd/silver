## Failure control, residual session work and physical lifetimes

construction belongs to this diagnostic side. A failed read preserves already
constructed ordinary-prefix state and unwinds. Input bytes remain fixed; an

Diagnostic allocation may cause GC. **The successful-prefix no-GC argument
does not extend through diagnostic formatting or serialization.** The reason
the shared-owner bound still applies is that these new owners neither resume
typing/registration nor construct new shared logical objects. The immutable
