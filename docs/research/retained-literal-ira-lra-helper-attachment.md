## Guard and failure behavior

The 31 helper local predicates use the `native_IRA_LRA_helper_` prefix;
`native_IRA_LRA_helper_conditional_capacity` exports their conjunction.
Exact accepted schemas, boolean computed values and a noncollision check
prevent replacing any inherited predicate. Both result maps retain all 335
actual values and add exactly 32 new values.

A false or uncomputed value in either inherited map skips new helper arithmetic.
Seven selected/core/ordinary/numeric capacity summaries are also required.
Then the helper leaf and all 32 new predicates are null, reasons distinguish
false from uncomputed prerequisites, and the named/composite result is false.

The checker forbids entering helper arithmetic on these paths. Computed local
failures retain the computed leaf and boolean false predicates with status
`computed`; null or a false conjunction cannot count as success.

`selected_named_IRA_LRA_helper_storage_established` exposes only the new
conditional named closure. The entire predecessor result is deep-copied.
